Development Summary

Day 1
------

8. Created the initial project structure.

Data Processing
---------------
1. Loaded all provided datasets using a dedicated DataLoader.
2. Parsed user, business, group, and historical message information.
3. Connected all contextual datasets for personalized routing.

Multimodal Processing
---------------------
1. Implemented text message processing.
2. Added EasyOCR for extracting text from image messages.
3. Added Faster-Whisper for speech-to-text transcription of voice notes.
4. Unified text, OCR output, and speech transcripts into a common text representation.

LLM Integration
---------------
1. Integrated Groq API.
2. Designed prompts to classify messages into the required message types.
3. Generated structured semantic outputs including:
   - message_type
   - urgency
   - importance
   - risk
   - spam score
   - summary
4. Fixed prompt formatting issues.
5. Corrected JSON parsing errors.
6. Handled API rate-limit issues during development.

Historical Retrieval
--------------------
1. Implemented TF-IDF vectorization.
2. Used cosine similarity to retrieve similar historical messages.
3. Returned supporting evidence_message_ids for explainability.

Personalization
---------------
Implemented routing using:
- User notification behaviour
- Group type
- Business verification
- User-business interaction history
- Notification fatigue
- Historical engagement

Safety Features
